# GAIM Prompt Safety Guardrails

## 목적

GAIM ai-engine의 프롬프트 가드레일은 OpenAI/Google provider의 안전 필터를 대체하지 않는다. provider 필터는 최후 방어선이고, GAIM 가드레일은 로컬 비즈니스 마케팅 도구에 맞는 안전한 생성 방향을 모델에 미리 지시하는 제품 정책 레이어다.

## 적용 범위

- 텍스트 생성: `/v1/text/generate`, `/v1/text/brand`, `/v1/text/marketing`, `/v1/text/refine`
- 이미지 생성/편집: 이미지 라우팅 경로, intent 경로, OpenAI/Google provider 직접 호출 경로
- 영상 생성: 숏폼 영상 job 프롬프트, deprecated provider 직접 영상 생성 경로

## 정책 원문

아래 두 정책 문구가 현재 ai-engine 프롬프트에 적용되는 GAIM 프롬프트 안전 가이드라인의 원문이다. 코드 기준 위치는 `ai-engine/app/services/text/prompts.py`이다.

### GAIM 마케팅 안전 정책

- 로컬 비즈니스 광고로 바로 사용할 수 있는 안전하고 사실 기반의 표현만 작성하세요.
- 성적·선정적 표현, 노골적 신체 묘사, 미성년자 성적 암시, 과도한 폭력·유혈·자해·범죄 조장, 혐오·차별 표현은 만들지 마세요.
- 불법 상품/서비스 홍보, 개인정보 노출, 타인 사칭, 유명인·실존 인물 사칭성 광고, 저작권·상표권 침해 유도는 피하세요.
- 의료·금융·법률 효능이나 결과를 보장하지 말고, 확인되지 않은 할인·재고·기간·순위·수상·인증·배송 약속을 만들지 마세요.
- 위험하거나 자극적인 요청은 가능한 경우 세련됨, 역동성, 신뢰감, 긴장감 같은 안전한 마케팅 표현으로 순화하세요.

### GAIM 시각 콘텐츠 안전 정책

- 광고 소재로 안전하게 사용할 수 있는 비성적, 비폭력적, 비혐오적 시각 표현만 사용하세요.
- 노골적 신체 노출, 선정적 포즈, 미성년자 성적 암시, 유혈·잔혹 묘사, 자해·범죄 실행 장면을 만들지 마세요.
- 실존 인물이나 유명인을 사칭하거나, 타 브랜드의 고유 표식·캐릭터·저작물을 모방하도록 지시하지 마세요.
- 위험하거나 자극적인 원문은 제품, 공간, 분위기, 조명, 구도 중심의 안전한 마케팅 장면으로 순화하세요.

## 정책 원칙

정책 원문을 적용할 때의 해석 원칙은 다음과 같다.

1. 안전한 대체 표현을 우선한다.
   - 위험하거나 자극적인 요청은 가능한 경우 세련됨, 역동성, 신뢰감, 긴장감 같은 안전한 마케팅 표현으로 순화한다.

2. 로컬 비즈니스 광고에 바로 쓸 수 있는 결과만 목표로 한다.
   - 확인되지 않은 혜택, 재고, 기간, 가격, 순위, 수상, 인증, 배송 약속은 만들지 않는다.
   - 의료, 금융, 법률 효능이나 결과를 보장하지 않는다.

3. provider 안전 필터에만 의존하지 않는다.
   - provider별 차단 기준과 실패 방식이 다르므로, fallback이 있는 ai-engine에서는 provider 호출 전 프롬프트 방향을 일관되게 맞춘다.

## 금지/회피 범주

아래 범주는 정책 원문에 포함된 주요 위험 범주를 운영자가 빠르게 확인하기 위한 요약이다.

- 성적·선정적 표현, 노골적 신체 묘사, 미성년자 성적 암시
- 과도한 폭력, 유혈, 자해, 범죄 조장 또는 범죄 실행 장면
- 혐오·차별 표현
- 불법 상품/서비스 홍보
- 개인정보 노출, 타인 사칭, 유명인·실존 인물 사칭성 광고
- 저작권·상표권 침해 유도, 타 브랜드 로고·캐릭터·저작물 모방
- 허위 할인, 허위 재고, 허위 긴급감, 확인되지 않은 보장 문구

## 구현 방식

- `marketing_safety_guardrails()`는 `GAIM 마케팅 안전 정책` 원문을 반환한다.
- `visual_safety_guardrails()`는 `GAIM 시각 콘텐츠 안전 정책` 원문을 반환한다.
- `_base_instruction()`은 텍스트 생성/재작성 프롬프트에 `marketing_safety_guardrails()`를 포함한다.
- `_build_chat_completion_kwargs()`의 system message는 사용자 요청보다 GAIM 마케팅 안전 정책을 우선 적용하도록 지시한다.
- `brand_image_prompt` 모드는 이미지 생성용 프롬프트를 작성하므로 `visual_safety_guardrails()`도 포함한다.
- 이미지 텍스트 렌더링 지시는 `text_to_render`와 `text_rendering.text`도 GAIM 마케팅 안전 정책과 시각 콘텐츠 안전 정책을 따라야 한다고 명시한다.
- 이미지 라우팅, intent 경로, OpenAI/Google 이미지 provider 호출, Veo 영상 provider 호출은 `append_visual_safety_guardrails()`를 통해 시각 콘텐츠 정책을 붙인다.
- `append_visual_safety_guardrails()`는 정책 섹션 제목이 이미 있으면 중복 삽입하지 않는다.

## 의도적으로 넣지 않은 것

- 별도 moderation API 호출
- 키워드 기반 요청 차단
- provider별 정책 전문 복제

이번 변경은 생성시간 영향을 작게 유지하기 위해 프롬프트 지침 보강만 적용한다. 실제 운영 로그에서 반복 차단, 악성 입력, provider fallback 실패가 확인되면 별도 validation 또는 moderation 레이어를 추가한다.
